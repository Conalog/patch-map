# Contributing to PatchMap

PatchMap is a PixiJS-based renderer for PATCH MAP data.

## Setup

The package supports Node.js 20 or newer. Use Node.js 22 for repository work,
matching `.nvmrc` and CI:

```sh
nvm use
npm ci
```

Start the Korean manual Lab with `npm run lab`.

## Verification

Run the checks relevant to your change:

- `npm run typecheck`
- `npm run lint`
- `npm run unit`
- `npm run build`
- `npm run verify:package`

## Pull requests

Keep pull requests focused and describe the checks you ran.
