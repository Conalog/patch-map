# Tests

Tests are grouped by the boundary they prove.

| Area | Purpose |
| --- | --- |
| `semantic/` | pure state, parsing, geometry, and policy |
| `core/` | committed runtime and publication integration |
| `engine/` | product authorities and coordinators |
| `rendering/` | PixiJS adapters and render publication |
| `integration/` | public and cross-owner behavior |
| `contract/` | executable contract and evidence wiring |
| `tooling/` | repository, packaging, and performance tooling |

Start with the focused file, then use the gate routing in
[`docs/engineering/verification.md`](../docs/engineering/verification.md).
