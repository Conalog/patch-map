# Product Decision and Evidence Registry

The product owner resolved every previously open behavior decision on 2026-07-16.
This registry preserves stable OQ identifiers and records the normative decision plus
the remaining evidence obligation. `Resolved` means an implementation must follow the
decision; it does not mean the scenario is automated, Lab-verified, integration-
verified, or release-verified.

Where a decision preserves historically accepted input but exact normalized output is
not yet frozen, a sanitized fixture/expected pair remains mandatory before the affected
row advances beyond `spec-ready`. Missing evidence is never permission to reject the
input, invent output, or relax another gate.
