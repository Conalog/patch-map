# System map

JavaScript owners are listed below. Native ownership is defined in the
[dual-package architecture](flutter-implementation-plan.md); native focused tests
live in `packages/flutter/test/`. Cross-runtime behavior uses
[shared conformance](flutter-conformance-design.md).

Use the first matching row. Paths name primary owners and focused checks, not
every helper involved.
