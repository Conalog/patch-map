# Alpha 0 overflow와 전체 보기 이동 — 2026-10-30

판정: **PASS — 전체 보기 이동 병목 개선을 채택한다.** 전체 60fps나 전체 모바일/iOS 검증은 아니다.
계약은 [presentation layers](presentation-layers.md), 판정 기준은 [verification](../verification.md)이다.
패키지 렌더 계획만 변경했다.

## 원인과 변경

`show:true`·alpha 0 텍스트는 그리기를 생략하지만 회전을 고려한 보수적 경계가 남아 있었다.
이웃과 겹치는 경계가 정적 배경 묶음을 막았고, item별 배경 제출이 막대 묶음도 끊었다.

- 기존 공통 기하 계산에서 alpha 0인 component를 제외한 임시 경계를 구한다.
  실제 item 경계, 보이는 텍스트·이미지 돌출, 겹침과 기존 그리기 순서는 유지한다.
- 현재 화면에 필요한 chunk에서만 묶음 가능 여부를 확인하고 현재 opacity
  snapshot에 저장한다. 매 프레임 다시 검사하지 않는다.
- 전체 경계가 같아도 그 안의 보이는 component가 움직이면 결과를 무효화한다.
  기존 객체를 직접 변경하는 갱신도 commit 전에 해당 변경 정보를 전달한다.
- 배경 꼭짓점의 소유권을 묶음 가능 여부와 분리했다. 숫자를 숨기거나 드러낼 때
  배경 자체가 같으면 기존 꼭짓점을 공유한다. 마지막 참조에서 해제한다.

공개 데이터·show·조회/히트 경계·텍스트 자원·선택·갱신 완료 계약과 모바일 alpha 정책은 유지한다.
부분 alpha나 실제 item 겹침은 기존 item별 그리기를 유지한다.

## 폐기한 중간 후보와 남는 비용

첫 후보 B는 숨은 텍스트의 경계만 제외했다. 규칙 fit 첫 제출이 188.16 →
219.36ms로 악화되어 그대로 채택하지 않았다. 별도 fit CPU profile 172 samples 중
`StaticGeometry.tryBuild`가 72, 좁힌 겹침 검사는 16 samples였다. 배경을 fit 때마다
다시 만드는 비용이 주요 원인이었다. C는 동일 배경의 꼭짓점을 유지하므로 이
재생성을 없앴고 fit도 개선됐다. 다른 최적화를 섞지 않았다.

C 전체 보기 profile 618 samples에서 남은 component/Map·alpha 조회, 막대 제출은 추가 변경하지 않는다.

## 외형·메모리·기능 범위

- 확대 화면의 지도 crop은 규칙/랜덤 모두 A/C 픽셀이 같았다.
- 전체 축소는 기존 Canvas 배경 대신 이미 채택된 정적 기하 경로를 사용하므로
  테두리 AA는 픽셀 일치하지 않는다. crop의 변경 픽셀은 규칙 21.44%, 랜덤 4.80%,
  RGB RMSE는 각각 25.33/8.09였다. 작은 패널의 테두리가 반복돼 비율이 커지며,
  규칙 배치의 가는 격자선이 더 선명해 보인다. 화면 검사에서 내용 누락·순서 변경은
  없었다. 정확한 Canvas AA 일치를 새로 보장하는 변경은 아니다.
- 배경 소유권 분리에는 메모리 교환이 있다. overlap 때문에 당장 그릴 수 없어도
  현재 chunk의 배경 한 벌을 유지한다. 과거 plan/node나 이전 opacity 목록은
  보관하지 않는다. 마지막 소유자 해제를 테스트했다.
- 보조 `dumpsys meminfo` snapshot의 규칙 전체 보기 PSS는 A2 1,123MiB,
  C 1,128MiB, Graphics는 각각 438/467MiB였다. 재확대 PSS는 1,013/796MiB였다.
  반복 횟수·CPU profile 유무가 달라 메모리 증감 판정에는 사용할 수 없다. GPU 상한·장기 누수 검증도 아니다.
- 렌더링/retained 갱신 관련 기존 32개 및 신규 5개, 위젯 presentation 8개 통과.
  숨김·부분 alpha·clear·회전·실제 overlap·전체 경계가 같은 내부 이동·retained
  staging·배경 공유/마지막 해제를 확인했다. 공개 hit/선택도 기존 동작을 유지했다.
- 대상 analyze/format/diff와 문서 검증을 실행했다. 독립 리뷰에서도 추가 확정 결함은 없었다.
  전체 suite, iOS, 네트워크/API 및 손가락 입력 matrix는 반복하지 않았다.
