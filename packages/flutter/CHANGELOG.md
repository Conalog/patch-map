# Changelog

Initial release planned as `1.0.0-alpha.1`. The first release PR generates its
versioned changelog entry.

- Add an independent Dart controller and native Flutter Canvas renderer.
- Implement dataset queries, atomic updates, history, editor workflows,
  viewport/transforms, presentation, touch input, accessibility and PNG capture.
- Ship native image/font adapters and isolated asset runtime/session ownership.
- Add common npm/Dart behavior fixtures, Android/iOS comparison scenes and
  installed consumer verification. Registry publication requires complete release
  qualification.
