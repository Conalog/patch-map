# Model admission targets

`cases.json` carries finite authored inputs and expected admission decisions.
It covers element/component kinds, inherited fields,
placements, relation compatibility, transform metadata and invalid inputs.
`expected.json` preserves reviewed normalization targets.

These files are implementation targets. Current Flutter has no public model or
model runner; no passing execution is inferred from the saved expectations.
Revalidate the baseline against the current JavaScript package before using it
as qualification evidence. Installed assets, gestures, raster output and native
OS execution require separate witnesses.
